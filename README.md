# Customer & Sales Analytics — End-to-End Data Analytics Project

## 📌 Project Overview

Customer & Sales Analytics is an end-to-end data analytics project focused on understanding customer behaviour, sales performance, profitability, and business trends.

The project follows a complete data analytics workflow starting from raw CSV data and progressing through data cleaning, exploratory analysis, SQL analysis, customer insights, and interactive Power BI dashboard development.

The main objective is to transform raw business data into meaningful insights that can support data-driven decision-making.

---

## 🎯 Business Objectives

- Analyse overall sales and profit performance
- Understand customer purchasing behaviour
- Identify high-value and low-value customer segments
- Analyse product and category performance
- Compare regional sales performance
- Identify sales and profit trends
- Calculate important business KPIs
- Create an interactive dashboard for business reporting
- Generate actionable business insights

---

## 🛠️ Tools & Technologies

- **Excel** — Data cleaning, validation and initial analysis
- **Python** — Data cleaning, exploratory data analysis and customer analysis
- **SQL** — Data querying, aggregation and business analysis
- **Power BI** — Data modelling, DAX and interactive dashboard
- **Git & GitHub** — Project version control and portfolio documentation
